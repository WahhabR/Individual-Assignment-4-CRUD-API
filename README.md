http://localhost:8080/birds/all will allow you to see the home page where all the birds will be listed.
You can click on the go to create page button and create a bird. You will then be able to see that bird in the home page. 
If you click on the bird it will take you to the details page which will show the bird's name and the color of the bird as well as buttons to go to the home page, update or delete.
